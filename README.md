## 🎯 About this tool
The pdf2md tool helps you turn PDF documents into clean Markdown files. Markdown is a simple text format. You use it to store notes, build websites, or keep documentation. This tool uses optical character recognition (OCR) to read text from images in your PDF files. It keeps the structure of your document intact, including headings, lists, and tables. 

This application saves you time. You do not need to copy and paste text manually. You do not need to spend hours fixing formatting errors. You select your file, click a button, and get your text.

## ❓ Frequently asked questions

### Does this tool send my files to the cloud?
No. The tool processes your files locally on your computer. Your data stays on your machine.

### Is my original file changed?
No. This tool creates a new file. It does not alter your original PDF.

### Can I convert multiple files at once?
The current version processes one file at a time to ensure high accuracy.

### Where do I find my result?
The result lands in the folder you selected during the conversion step. You can open the new `.md` file with any standard text editor or a specialized Markdown viewer. 

### Why does the text look different?
Markdown removes complex layout data to focus on content. It uses simple symbols to represent formatting like bold, italics, and headers. If you need the exact visual replica of a document, this tool might not be the right choice. If you need clean text for editing, this tool works perfectly.

## 🔧 Troubleshooting
If the application fails to start:
*   Check your internet connection and download the installer again.
*   Ensure that you have enough space on your hard drive.
*   Restart your computer if the installer hangs.
*   Antivirus software might block new applications. Check your security settings if the application fails to launch.

If the output text contains errors:
*   Open the PDF and zoom in. If the text looks blurry to you, the OCR tool will struggle to read it.
*   Ensure the document is a text-based PDF or a high-quality scan.
*   Rotate the PDF pages to the correct orientation before importing the file.
